# ELYND Worlds

Every meditation in ELYND gets its own painted world, designed, painted, checked and
brought to life with Meta's models.

Built for the Meta Global AI Developer Hackathon (Startup track, "Build for Your World"),
26 Oct – 4 Nov 2026. All code in this repository was written during the hackathon, after
the kickoff on 26 Oct. Work in progress: this README grows with the project.
